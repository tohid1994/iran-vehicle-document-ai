# موتور آفلاین استخراج اطلاعات برگ سبز خودرو

نسخه ۰.۱.۰ یک پیاده‌سازی اولیه و مستقل با Python، API و CLI است. پردازش تصویر
هیچ درخواست اینترنتی ندارد. مدل OCR انتخاب‌شده Tesseract با مدل فارسی و انگلیسی
محلی است. دقت روی برگ سبز واقعی هنوز ارزیابی نشده و خروجی باید بازبینی شود.

## نصب و اجرا

روی دستگاه متصل به اینترنت، Python 3.11 به بالا و Tesseract 5 را نصب کنید:

```bash
sudo apt-get install tesseract-ocr
python -m venv .venv
. .venv/bin/activate
pip install .
python scripts/prepare_models.py
vehicle-document-ai extract vehicle.jpg --models models --output result.json
vehicle-document-ai serve
```

مدل‌ها فقط در مرحله آماده‌سازی دریافت می‌شوند. هنگام پردازش، نبودن مدل یا عدم تطابق
Checksum باعث خطا می‌شود؛ دانلود خودکار انجام نمی‌شود. برای انتقال همه وابستگی‌ها
به سرور آفلاین، روش Docker در README انگلیسی و docs/offline.md را دنبال کنید.
فایل نصب بومی Python به‌تنهایی شامل Tesseract و کتابخانه‌های سیستمی آن نیست.

## API

```bash
curl -F 'file=@vehicle.jpg' http://127.0.0.1:8000/api/v1/documents/extract
```

مسیر analyze اطلاعات کیفیت و متن و مختصات را برمی‌گرداند. مسیر health زنده‌بودن
سرویس و آمادگی OCR را جداگانه نشان می‌دهد. قرارداد کامل در openapi.json موجود است.
برای شبکه، کلید IVDAI_API_KEY و TLS و محدودسازی نرخ درخواست در reverse proxy لازم است.

## معنای خروجی

سیستم سند به brand، تیپ به model و مدل به year نگاشت می‌شود. مقادیر نامعلوم،
شناسه‌های نامعتبر و موارد متعارض null می‌مانند. نام کامل خودکار شکسته نمی‌شود و
داخلی یا خارجی بودن خودرو بدون بانک معتبر تعیین نمی‌شود. Confidence کالیبره‌شده
فعلاً null است؛ engineScore فقط امتیاز خام OCR است. همه فیلدها نیازمند بازبینی هستند.
موفقیت خروجی به معنی تأیید اصالت سند یا درست‌بودن تمام اطلاعات نیست.

API به‌صورت پیش‌فرض تصویر را نگه نمی‌دارد و خطاها متن سند را نمایش نمی‌دهند. فایل
JSON خروجی حاوی اطلاعات حساس است و نباید لاگ یا عمومی شود. هیچ سند واقعی در این
پروژه قرار نگرفته است. تصاویر آزمون، ساختگی هستند.

پشتیبانی از قالب‌های مختلف از طریق عنوان‌ها و Template اختیاری پیاده شده، اما
Template معتبر برگ سبز واقعی همراه پروژه نیست. پلاک بدون عنوان، نویز و انعکاس نور
و تفاوت قالب ممکن است باعث استخراج ناقص شوند. اجرای CPU بدون AVX2 نیازمند Runtime
سازگار و آزمون روی سخت‌افزار واقعی است. مجوز کد MIT و مجوز مدل‌ها Apache-2.0 است.
